# Testing Practice

This project is a practice assignment from a JavaScript course focused on writing unit tests with Jest. It includes functions and their corresponding tests.

## Features
- **capitalize**: Capitalizes the first letter of a string.
- **reverseString**: Reverses a given string.
- **calculator**: An object with methods for basic arithmetic (add, subtract, divide, multiply).
- **caesarCipher**: Shifts each letter in a string by a given number, preserving case and punctuation.
- **analyzeArray**: Analyzes an array of numbers and returns an object with average, min, max, and length.
